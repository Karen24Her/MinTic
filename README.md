# ✅ App de tareas para Android

Aplicación móvil en **Kotlin** para registrarse y gestionar una lista de tareas guardadas en el teléfono con **Room**. Desarrollada en el programa de formación de MinTIC.

## Funcionalidades

- Pantalla de bienvenida y registro de usuario.
- Lista de tareas con detalle de cada una.
- Creación de nuevas tareas.
- Almacenamiento local con la base de datos Room (entidad, DAO y base de datos).
- Navegación entre secciones con fragmentos y menú lateral.

## Tecnologías

Kotlin · Android Studio · Room · Navigation Component

## Cómo ejecutarla

1. Clona el repositorio: `git clone https://github.com/Karen24Her/MinTic.git`
2. Ábrelo en Android Studio.
3. Ejecuta la app en un emulador o en un teléfono Android.

## Estructura

```
app/src/main/java/com/example/mintic/
├── room_database/      entidad ToDo, DAO y base de datos
├── ToDoActivity.kt     lista de tareas
├── NewTaskActivity.kt  creación de tareas
├── DetailFragment.kt   detalle de una tarea
└── RegisterActivity.kt registro de usuario
```
